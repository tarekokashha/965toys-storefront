# Source notes

The `source/woodmart-child/` folder is a reviewed text-only snapshot of the local 965toys child theme. It contains 17 PHP files, four CSS files, and one JavaScript file.

It excludes the commercial Woodmart parent theme, font binaries, graphics, archives, deployment configuration, customer data, and orders. The missing assets and production content mean this folder should not be treated as a ready-to-install store.

The public site currently shows a coming-soon page. This repository does not claim that the included child theme is deployed there.

Static checks found no credential assignments in the included files. PHP runtime checks were unavailable in the review environment, so execution and WordPress compatibility have not been verified here.
